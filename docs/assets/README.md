## GitHub social preview (Open Graph)

GitHub's repository social preview is **1280×640** (2:1). This repository
does not ship a separate marketing hero, and it does not publish fake
star, download, or finding counts.

To set the preview:

1. Open the repository on GitHub → **Settings** → **General** → **Social
   preview**.
2. Upload a **crop** of `tui-adaptive-redteam.png` that keeps the header
   and model board visible. Do not overlay invented metrics.
3. If you recapture the screenshot, use a real `cot-redteam tui` session
   against a config you are authorized to run.

Link unfurls that scrape the README already show this image even before a
custom social preview is uploaded.

# Code of Conduct

## Our pledge

This project adopts the
[Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in full. Its standards, enforcement responsibilities, scope, and enforcement
guidelines govern participation in this project.

In particular, project participants must:

- contribute respectfully and constructively;
- address technical claims with evidence rather than personal attacks;
- respect privacy, confidentiality, consent, and research authorization;
- accept feedback and take responsibility for mistakes;
- avoid harassment, discrimination, threats, doxxing, sexualized conduct, and
  deliberate disruption.

The code applies in repository discussions, issues, pull requests, reviews, and
other spaces where someone represents the project.

## Reporting and enforcement

For conduct involving GitHub content, use GitHub's private **Report content**
or **Report abuse** action on the relevant issue, pull request, discussion,
comment, repository, or user. GitHub documents the available private reporting
paths in its
[abuse-reporting guide](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

Do not publish incident details or another person's private information in a
new issue. If the concern cannot be attached to existing content, contact
GitHub Support through the private reporting path described in that guide.

Maintainers may remove or edit contributions, limit participation, or ban
participants when necessary to enforce this policy. Reports will be handled as
confidentially as practical, with consideration for the safety and privacy of
everyone involved.

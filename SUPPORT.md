# Support

## Usage questions

Read the [README](README.md) and guides under [`docs/`](docs/) first. For a
question that may help other users, open a GitHub Discussion when Discussions
are enabled.

## Reproducible bugs

Use the bug-report issue template and include:

- package and Python versions;
- operating system;
- redacted configuration;
- command and exit code;
- expected and actual behavior;
- a minimal offline reproduction when possible.

Remove API keys, authorization headers, proprietary prompts, model responses,
database contents, and provider request identifiers before posting.

## Feature requests

Use the feature-request template. Explain the concrete workflow, why existing
extension points are insufficient, and the expected maintenance or operational
cost.

## Security

Do not open a public issue for a suspected vulnerability. Follow
[SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.

## Support expectations

This is a community-maintained research project. Support, response times, and
compatibility with unlisted providers are best effort and are not covered by a
service-level agreement.
